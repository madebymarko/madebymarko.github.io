# madebymarko.github.io

Personal portfolio site for Mark Magweregwede — Software Developer (AI & Machine Learning · Data Analytics).

A single-file, dependency-free static site (`index.html`).

## Live site

**🌐 Published via GitHub Pages: [madebymarko.github.io](https://madebymarko.github.io)** — every push
to `main` on the `madebymarko/madebymarko.github.io` repo redeploys it automatically.

## Local preview

There is no build step and no dependencies. Either:

- Open `index.html` directly in a browser, or
- Serve it locally (useful for testing relative paths / the PDF link):

```bash
node serve.cjs
```
